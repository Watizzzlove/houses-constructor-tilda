# Конструкторы домов и бань «Дока» (Tilda)

Реализован законченный вариант одного конструктора. Полностью отдебажен и настроен на работу с яндекс-диском по апи. Все дальнейшие конструкторы будут делаться по нему 

В данном репозитории содержатся автономные интерактивные конструкторы домов и бань для вставки на платформу Tilda, правила организации медиафайлов, а также структура каталогов проектов.

---

## 1. Структура репозитория

```text
├── pages/                      # Готовые автономные HTML-страницы конструкторов для Tilda
│   └── house-taganay.html      # Интерактивный конструктор дома «Таганай»
├── project_doka/               # Целевая структура каталога медиа (без тяжелых фото)
│   ├── houses/                 # Модели домов (taganay_v2 и др.)
│   └── saunas/                 # Модели бань
└── README.md                   # Документация проекта
```

> **Примечание:** Сами файлы фотографий исключены из Git-репозитория из-за ограничений по размеру. В репозитории зафиксирована структура каталогов (дерево папок сохранено с помощью `.gitkeep`).

## 2. Как работает конструктор в Tilda

Конструктор (`pages/*.html`) представляет собой полностью автономный бандл, не требующий внешних npm-пакетов или серверной части Node.js:
1. **HTML, CSS и JS** объединены в одном файле.
2. При загрузке страницы скрипт читает блок конфигурации `<script type="application/json" data-hc-config>`:
   - Тип проекта (`typeName`), название серии (`seriesName`);
   - Ссылка для кнопки заявки (`ctaHref`, например `#popup:calculation`);
   - Провайдер медиа (`media.provider`: `yandexDisk` или `placeholder`) и путь к серии (`media.seriesPath`).
3. Конструктор динамически опрашивает API облачного диска, парсит существующие папки размеров, типов входных групп, вариантов террас и цветов, автоматически выстраивая интерфейс и рассчитывая стоимость.
4. При смене цвета или комплектации подгружаются соответствующие фотографии (вид снаружи, планировки, интерьер).

## 3. Целевая структура каталога медиа (`project_doka`)

Структура `project_doka` спроектирована для автоматического распознавания конфигуратором размеров, цен и фотографий.

### Иерархия папок

```text
project_doka/
└── houses/ (или saunas/)
    └── <series_slug>/                          # Пример: taganay_v2
        └── <width>x<length>__p<price>/         # Размер дома и базовая цена
            ├── beige/                          # Базовый дом без террасы (бежевый)
            │   ├── main.jpg                    # Главное фото экстерьера
            │   └── exterior_2.jpg
            ├── bronze/                         # Базовый дом (бронза)
            ├── graphite/                       # Базовый дом (графит)
            ├── porch/                          # Вариант с крыльцом
            │   └── <w>x<l>__p<price>/          # Размер крыльца и цена под ключ
            │       ├── beige/
            │       ├── bronze/
            │       └── graphite/
            └── terrace/                        # Вариант с террасой
                ├── covered/                    # Крытая терраса
                │   └── <w>x<l>__p<price>/      # Размер террасы и цена под ключ
                │       ├── beige/
                │       ├── bronze/
                │       └── graphite/
                └── open/                       # Открытая терраса
                    └── <w>x<l>__p<price>/      # Размер террасы и цена под ключ
                        ├── beige/
                        ├── bronze/
                        └── graphite/
```

### Правила именования папок размеров и цен

Формат: `<ширина>x<длина>__p<полная_цена>`:
- Разделитель размеров — строго латинская строчная буква **`x`** (не русская «х» и не знак «×»).
- Дробные значения указываются через точку: `1.5x2.5`.
- Суффикс `__p` указывает полную итоговую стоимость конфигурации (в рублях, целое число без пробелов и знаков валюты).
- **Примеры:**
  - `5x6__p1622000` — дом 5×6 м, базовая цена 1 622 000 ₽.
  - `terrace/covered/5x2__p1709000` — дом с крытой террасой 5×2 м общей стоимостью 1 709 000 ₽.

### Папки цветов фасада

Внутри размерной папки создаются папки доступных цветов:
- `beige` — Бежевый (сосна / светлое дерево)
- `bronze` — Бронза (орех / шоколад)
- `graphite` — Графит (темно-серый / антрацит)

Если для какого-либо размера определенный цвет не предусмотрен или фото отсутствуют, соответствующая папка не создается — конструктор автоматически скроет недоступный цвет.

## 4. Правила именования файлов фотографий

Внутри конечной папки цвета файлы именуются в строгом формате, определяющем тип кадра и порядок в галерее:

| Шаблон имени | Назначение | Приоритет сортировки |
| :--- | :--- | :--- |
| `main.jpg` / `.webp` | Главное фото карточки проекта (обязательно) | 1 (всегда первый кадр) |
| `exterior_1.jpg`, `exterior_2.jpg` | Дополнительные ракурсы снаружи | 2 |
| `plan_1.jpg`, `plan_2.png` | Планировки и чертежи (отображаются без обрезки) | 3 |
| `interior_1.jpg`, `interior_2.jpg` | Фотографии интерьера помещений | 4 |
| `real_1.jpg`, `real_2.jpg` | Реальные фотографии с готовых объектов | 5 |
| `detail_1.jpg` | Макро-кадры, узлы, фактура материалов | 6 |

- **Поддерживаемые форматы:** `.jpg`, `.jpeg`, `.png`, `.webp`.
- Порядок номеров: натуральная сортировка (`exterior_2` идет перед `exterior_10`).

## 5. Размещение конструктора на Tilda

1. Открыть страницу в редакторе Tilda.
2. Добавить блок **T123** («HTML-код») или блок Vibe.
3. Скопировать и вставить весь код из `pages/house-taganay.html`.
4. В конфигурационном JSON (тег `<script type="application/json" data-hc-config>`) при необходимости изменить:
   - `ctaHref` — якорь попапа Tilda (по умолчанию `#popup:calculation`);
   - `publicKey` — публичная ссылка на папку Яндекс.Диска с медиафайлами.
5. Опубликовать страницу.
